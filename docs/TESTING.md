# Проверка Telegram-версии

Дата проверки: 12 октября 2026 года.

## Автоматические тесты

Запуск из корня: `.\.venv\Scripts\python.exe -m pytest -q`.

24 теста проходят. Используются временные базы и подставной HTTP-транспорт. Проверены:

- Пустой, короткий и слишком длинный текст; неверные и прошедшие даты.
- Разбор даты отдельной строкой без изменения дат в содержании задания.
- Сохранение после повторного открытия БД, смена дедлайна без потери отметок.
- Изоляция пользователей, недействительность кнопок после замены плана.
- TTL от последней активности, каскадное удаление.
- PDF без текста, файл другого типа, лимит памяти скачивания.
- Приоритет текста над приложенным файлом.
- Один повтор неверного JSON; 429, таймаут и недоступность модели.
- Один активный разбор на пользователя и пять на процесс.
- Сохранение прежнего плана при ошибке нового разбора.
- Весь диалог через aiogram Dispatcher, включая callback из сообщения бота и сбор текста частями.
- Безопасное разбиение длинных ответов по лимиту Telegram.

Проверка `getMe` подтвердила имя `Deadlinebud_bot`. Webhook отсутствует. Фоновый процесс начал long polling. Пользователь отдельно подтвердил реальный короткий ответ `API works` от `Qwen3.8-27B`.

Полный AI-разбор контрольных заданий запускается `backend/check_ai.py --all`. Автоматические тесты не считаются проверкой качества живой модели. На момент передачи полный AI-сценарий в среде запуска не подтверждён.

## Ручная приёмка

1. Отправить `/start`, затем пример из REPORT.md; проверить цель, требования и 3–12 шагов.
2. Отметить шаг; `/plan` должен сохранить отметку.
3. Указать будущую дату, затем сегодняшнюю; отметка остаётся, даты обновляются.
4. Перезапустить процесс и запросить `/plan`.
5. Отправить PDF с выделяемым текстом, PDF-скан, файл больше 5 МБ и DOCX; сверить результаты с таблицей ошибок.
6. Отправить `/new`, две части текста и нажать «Разобрать».
7. Отправить новое задание; старая кнопка не должна менять новый план.
8. Отправить `/delete`; после этого `/plan` должен предложить создать новый план.

Для иллюстраций инструкции нужны снимки настоящего чата: приветствие, отправленное условие, результат разбора, отмеченный шаг и план с датами. Они должны быть получены после ручного сценария. Скриншоты предыдущего сайта сохранены только в архиве и не выдаются за Telegram-версию.
