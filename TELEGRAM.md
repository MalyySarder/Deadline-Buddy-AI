# Deadline Buddy в Telegram

Бот: https://t.me/Deadlinebud_bot

Статус: подготовлен транспорт и безопасная проверка подключения. Это подготовка первого задания (Deadline Buddy), не реализация проекта «Баг из слов». Перенос бизнес-сценариев выполняется после получения обновлённого ТЗ.

## Конфигурация

`backend/.env` содержит `TELEGRAM_BOT_TOKEN` и `TELEGRAM_BOT_USERNAME`. Файл исключён из Git и Docker-контекста. Реальный ключ не переносить в `.env.example`, сообщения, скриншоты или журналы. При смене токена заменить значение в `.env` и перезапустить процесс.

Токен Telegram управляет ботом, но не заменяет ключ языковой модели. `LLM_API_KEY`, `LLM_BASE_URL` и `LLM_MODEL` настраиваются отдельно. Сейчас модель не подключена.

## Проверка без запуска

Из корня проекта:

```powershell
.\.venv\Scripts\python.exe backend/telegram_bot.py --check
```

Проверяет `getMe` и `getWebhookInfo`, выводит только имя, ID и состояние подключения. Не отправляет сообщения, не забирает пользовательские обновления и не меняет webhook.

## Ручной запуск основы

```powershell
.\.venv\Scripts\python.exe backend/telegram_bot.py
```

Long polling работает пока включён компьютер и запущен процесс. Домен и входящий публичный порт не нужны. Одновременно должен работать один экземпляр. При существующем webhook запуск отказывается продолжаться без его изменения. Остановка — Ctrl+C.

Основа отвечает в личном чате на `/start` и `/help`, честно сообщает о подготовке. Остальные сообщения и файлы не анализируются, не скачиваются и не сохраняются. Группы игнорируются. Полноценная обработка PDF и LLM пока не подключена. Не запускается автоматически при импорте или при запуске веб-версии.

## После обновлённого ТЗ

- Согласовать команды, кнопки и сценарий задания → чек-лист → дедлайн.
- Связать планы с Telegram user ID вместо cookie, проверить изоляцию пользователей.
- Определить хранение, удаление данных, часовой пояс и перенос дат.
- Подключить выбранный LLM API и обработку ошибок/лимитов.
- Согласовать получение PDF и ограничения файлов.
- Добавить надёжную обработку обновлений, защиту от дублей и повторную доставку ответов.
- Настроить постоянное размещение, автозапуск, контроль доступности и резервные копии.

До этого документ не утверждает готовность бота к реальному учебному использованию. Веб-версия сохранена для переноса проверенной логики. Публиковать обновлённую пользовательскую инструкцию следует после проверки настоящих сценариев бота.
